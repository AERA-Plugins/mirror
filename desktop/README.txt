AERA Mirror - USB connection

1. In AERA Recovery, open AERA Mirror and choose Connect over USB.
2. Install Android platform-tools (ADB) on this computer.
3. Keep the phone connected by USB and approve Start USB Mirror.
4. Windows: run start-aera-mirror-usb.cmd
   Linux: run sh start-aera-mirror-usb.sh
   macOS: run start-aera-mirror-usb.command
5. Your browser opens http://127.0.0.1:8080/ automatically.

Wi-Fi mode needs none of these files. Open the address displayed by AERA.
